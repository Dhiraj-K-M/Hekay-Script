## Philosophy

- Easy to Learn

- Easy to Build

- Powerful for Robotics
- Powerful for Games
- Powerful for Software Development
- Powerful for Space Technology

---

## Rule 1

One statement per line.

Example

show "Hello"

---

## Rule 2

Semicolon (;) is NOT required.

Correct

show "Hello"

Wrong

show "Hello";

---

## Rule 3

Blocks use Curly Braces {}

Example

if age >= 18 {

    show "Adult"

}

---

## Rule 4

Comments

Single Line

// This is a comment

Multi Line

/*
This
is
a
comment
*/

## Rule 5

het name = "Hekai"

hook PI = 3.14159
