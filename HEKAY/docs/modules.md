## What is a Module?

A module is a reusable file that contains functions, classes, or variables.

---

## Module Keywords

| Keyword | Description |
| ---------- | ------------- |
| `inport` | Import a module |
| `outport` | Export functions, classes, or variables |

---

## Import Example

```hky
inport math
```

---

## Export Example

```hky
outport Calculator
```

---

## Notes

- Modules help organize large projects.
- One module can be used in multiple projects.
- Use `inport` to include modules.
- Use `outport` to share modules.
