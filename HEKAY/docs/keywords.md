## Variables

het
hook

Description:

het   -> Mutable Variable (Value can be changed)

hook  -> Constant Variable (Value cannot be changed)

Example

het name = "Hello"

hook PI = 3.14159

---

## Input / Output

show
input

Description:

show  -> Display output on screen

input -> Take input from user

Example

show "Hello World"

input username

---

## Conditions

if

elif

else

match

case

default

Description:

if       -> First condition

elif     -> Additional condition

else     -> Default condition

match    -> Multiple condition checking

case     -> Match option

default  -> Default case

---

## Loops

loop

while

for

break

continue

Description:

loop      -> Infinite/Custom Loop

while     -> Run while condition is true

for       -> Counter Loop

break     -> Stop loop

continue  -> Skip current iteration

---

## Functions

func

return

Description:

func      -> Create Function

return    -> Return value

Example

func hello()

show "Hello"

return

## Classes

class

new

this

super

extends

Description:

class      -> Create Class

new        -> Create Object

this       -> Current Object

super      -> Parent Class

extends    -> Inherit Class

## Modules

inport

outport

Description:

inport     -> Import Module

outport    -> Export Module

Example

inport math

outport calculator

## Error Handling

try

catch

throw

finally

finally    -> Always Execute
