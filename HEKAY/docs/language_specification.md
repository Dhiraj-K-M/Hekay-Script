# Hekay Programming Language Specification

**Developer:** Dhiraj Kumar Mehangiya

**Language:** Hekay

**File Extension:** `.hky`

**Version:** 1.0

**Status:** Draft

## Introduction

Hekay is a modern, high-performance, general-purpose programming language designed to be simple, readable, secure, and powerful.

It is built for:

- Artificial Intelligence (AI)
- Robotics
- Web Development
- Desktop Software
- Mobile Applications
- Android Applications
- Game Development
- Operating Systems
- Space Technology
- Future Computing

---

## Design Goals

- Easy to Learn
- Easy to Read
- Easy to Build
- High Performance
- Beginner Friendly
- Secure by Design
- Future Ready
