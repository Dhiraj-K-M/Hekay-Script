## Arithmetic Operators

| Operator | Description |
| ---------- | ------------- |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Remainder (Modulo) |
| `**` | Power (Exponent) |

### Example

```hky
het x = 10 + 5
```

---

## Assignment Operators

| Operator | Description |
| ---------- | ------------- |
| `=` | Assign Value |
| `+=` | Add and Assign |
| `-=` | Subtract and Assign |
| `*=` | Multiply and Assign |
| `/=` | Divide and Assign |
| `%=` | Modulo and Assign |

### Assignment Example

```hky
het score = 100

score += 10
```
