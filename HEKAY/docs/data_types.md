# Hekay Official Data Types v1.0

Developer: Dhiraj Kumar Mehangiya

---

## Number

Stores whole numbers.

Example

het age = 18

---

## Decimal

Stores decimal numbers.

Example

het pi = 3.14159

---

## Text

Stores text.

Example

het name = "Hekai"

---

## Boolean

Stores true or false.

Example

het online = true

---

## List

Stores multiple values.

Example

het numbers = [10, 20, 30]

---

## Object

Stores custom objects.

Example

class Robot {

}

het bot = new Robot()

---

## Null

Represents an empty value.

Example

het value = null
